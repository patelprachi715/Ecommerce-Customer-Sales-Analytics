# Python Analysis

Python was used for additional data analysis and visualization in this project.

## Tasks Completed
- Loaded the cleaned Online Retail dataset
- Performed data quality checks
- Removed invalid price rows
- Created revenue and date-based columns
- Analyzed top countries by revenue
- Analyzed top products by revenue
- Analyzed top customers by revenue
- Calculated monthly revenue trends
- Created customer segments
- Created visualizations using matplotlib

## Files
- ecommerce_analysis.ipynb: Python notebook for data analysis
- Python output CSV files are saved in the Python_Output folder
- Python chart images are saved in the Images folder
